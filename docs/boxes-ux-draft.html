Responsive rule: use the width and height the host gives the app. Narrow panes drill from list → box, with a Back button. Wide panes show list + workspace. The workspace content scrolls; its destination and input stay visible. No separate manager UI.
Data rule: show API-visible boxes, including ones created in the Discobox console. Nest only known parent/child relationships. A child whose parent is absent stays visible at the top level. Permissions affect available actions, not whether a box deserves a different UI.
